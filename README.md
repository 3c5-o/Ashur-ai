# Ashur AI

واجهة محادثة عربية متقدمة تعمل عبر Vercel Serverless Functions.

## المميزات الحالية

- Streaming للرد بشكل تدريجي.
- محادثات متعددة مع بحث، إعادة تسمية وحذف.
- حفظ المحادثات والإعدادات محلياً على الجهاز.
- تعديل الرسالة وإعادة التوليد.
- إيقاف الرد أثناء التوليد.
- Markdown وكتل كود مع زر نسخ.
- أوضاع: عام، كتابة، برمجة، دراسة، تلخيص، ترجمة.
- رفع صور وملفات نصية وPDF.
- إدخال صوتي وقراءة الرد صوتياً عند دعم المتصفح.
- وضع داكن وفاتح وحجم خط ودرجة إبداع.
- تصدير المحادثة Markdown.
- PWA وتثبيت على الشاشة الرئيسية.
- حماية للـAPI ورسائل خطأ عامة.
- عدم إظهار معلومات المزود أو النموذج داخل واجهة المستخدم.
- مصدر تجريبي إضافي متوافق مع OpenAI عبر إعدادات داخلية.
- اختيار موديل تجريبي وبيانات تدريب وMarkdown.
- اختبار اتصال للمصدر التجريبي.
- رجوع تلقائي للمصدر الأساسي عند فشل المصدر التجريبي.
- دعم مفتاح تجريبي مؤقت في الجلسة أو متغير Vercel باسم `AIGATE_API_KEY`.

## النشر

المشروع يعمل من فرع `main` ومهيأ للنشر على Vercel.

يلزم وجود مفتاح الخدمة في Environment Variables كما هو مضبوط في مشروع النشر الحالي.

> لا تضع أي مفتاح سري داخل المستودع العام.

## تحسينات البرمجة والإخراج الطويل

- إدخال رسائل حتى 180,000 حرف، مناسب للصق ملفات وأكواد ضخمة.
- وضع إخراج برمجي طويل مع تكملات تلقائية تُدمج داخل نفس رسالة المساعد.
- صندوق أكواد احترافي مع:
  - عدد الأسطر.
  - نسخ.
  - تنزيل كملف حسب اللغة.
  - تكبير ملء الشاشة.
  - أرقام أسطر.
- رفع حد الملفات النصية وقراءة PDF أكبر.
- ضغط الصور تلقائياً قبل رفعها لتقليل أخطاء حجم الطلب.
- عند إرفاق صورة مع المصدر التجريبي، يتم توجيه الطلب داخلياً إلى مسار يدعم الصور بدلاً من رفضه.

## إنشاء الصور

- مسار خادم: `/api/image`.
- إنشاء الصور عبر الخادم التجريبي.
- النماذج المتاحة في الواجهة: `flux` و`flux-realism` و`flux-anime` و`sana`.
- الصور تظهر داخل المحادثة مع فتح وتنزيل.
- المفتاح يؤخذ من `AIGATE_API_KEY` على Vercel، أو مؤقتاً من جلسة المتصفح عند الاختبار.
