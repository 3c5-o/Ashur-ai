# Ashur AI

واجهة محادثة عربية متقدمة تعمل عبر Vercel Serverless Functions.

## المميزات الحالية

- Streaming للرد بشكل تدريجي.
- محادثات متعددة مع بحث، إعادة تسمية وحذف.
- حفظ المحادثات والإعدادات محلياً على الجهاز.
- تعديل الرسالة وإعادة التوليد.
- إيقاف الرد أثناء التوليد.
- Markdown وكتل كود مع زر نسخ.
- أوضاع: عام، كتابة، برمجة، دراسة، تلخيص، ترجمة.
- رفع صور وملفات نصية وPDF.
- إدخال صوتي وقراءة الرد صوتياً عند دعم المتصفح.
- وضع داكن وفاتح وحجم خط ودرجة إبداع.
- تصدير المحادثة Markdown.
- PWA وتثبيت على الشاشة الرئيسية.
- حماية للـAPI ورسائل خطأ عامة.
- عدم إظهار معلومات المزود أو النموذج داخل واجهة المستخدم.

## النشر

المشروع يعمل من فرع `main` ومهيأ للنشر على Vercel.

يلزم وجود مفتاح الخدمة في Environment Variables كما هو مضبوط في مشروع النشر الحالي.

> لا تضع أي مفتاح سري داخل المستودع العام.
