# Ashur AI

نسخة أولية لتجربة واجهة محادثة مرتبطة بخدمة AI خارجية عبر بروكسي Serverless.

## الملفات

- `index.html` — واجهة المحادثة كاملة.
- `api/chat.js` — بروكسي الخادم الذي يتصل بخدمة AI ويمنع مشكلة CORS.

## التشغيل على Vercel

1. اربط هذا المستودع بمشروع Vercel.
2. لا تحتاج Build Command لهذه النسخة.
3. اترك Output Directory فارغًا.
4. انشر المشروع.
5. افتح رابط المشروع وأرسل رسالة.

المتصفح يتصل فقط بالمسار المحلي:

```
POST /api/chat
```

والبروكسي يتصل بالخدمة الخارجية:

```
GET https://camillecyrm.serv00.net/GPT-5-6/api
```

## ملاحظات

هذه نسخة اختبار. البروكسي عام حاليًا ولا يحتوي على مصادقة أو Rate Limiting دائم. قبل تحويل المشروع إلى خدمة إنتاجية يجب إضافة حماية، حدود استخدام، سجلات أخطاء، وسياسة واضحة للتعامل مع بيانات المحادثات.
